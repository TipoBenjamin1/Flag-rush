# Flag Rush v0.1.0 Release Notes

Date: 2026-06-05

This release marks the first OSS preparation pass for the real Flag Rush project in `flag-quiz-android`.

## Highlights

- Fast regional and world flag quiz gameplay.
- Timed questions, streaks, XP, ranks, and local player progress.
- Web build plus Capacitor Android and iOS projects.
- Codemagic workflows for iOS simulator, unsigned device, and signed App Store builds.
- Public contribution, security, roadmap, changelog, and asset provenance docs.
- Package metadata now matches the public Flag Rush repository.

## Verification

- `npm run lint`
- `npm run build`

## Notes

- Android release signing and iOS signing assets are intentionally not included.
- Store builds should be produced from trusted local or CI signing environments.
- Review the privacy policy draft and `ASSET_PROVENANCE.md` before publishing public store listings.
