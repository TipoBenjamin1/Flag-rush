## Why this repository qualifies

Flag Rush is an open-source, mobile-first geography learning game that helps players practice country flags across Europe, Asia, Africa, the Americas, Oceania, and the full world mode. It includes a React/TypeScript web app, Capacitor Android and iOS projects, local progress tracking, multilingual UI, country facts, and public OSS maintenance docs. The app is already published on Google Play, so the repository supports a real released mobile product, not only a demo. The project is useful for education, casual learning, and for contributors who want a real cross-platform app to improve.
