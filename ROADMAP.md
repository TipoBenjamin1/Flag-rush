# Roadmap

This roadmap is intentionally compact. It tracks the next practical steps for making Flag Rush easier to ship, maintain, and contribute to.

## Near Term

- Keep web, Android, and iOS builds passing in CI.
- Add a small smoke-test checklist for the main game loop.
- Confirm asset provenance for generated images, fonts, and store graphics.
- Improve bundle size by splitting non-critical game data or UI paths.

## Product Polish

- Tighten accessibility for keyboard and screen-reader navigation.
- Add more explicit reduced-motion behavior for animated screens.
- Improve offline behavior for remote flag images.
- Expand country facts and translations while keeping text quality high.

## Release Readiness

- Document Android signing steps without exposing secrets.
- Keep Codemagic iOS workflows current.
- Add release checklists for APK, AAB, and iOS artifacts.
- Publish updated release notes for every public build.
